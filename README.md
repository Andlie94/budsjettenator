# BUDSJETTENATOR

![MinBudsjett](https://images.unsplash.com/photo-1772588627499-baefc8ab0ce7?w=500&auto=format&fit=crop&q=60&ixlib=rb-4.1.0&ixid=NHwxMjA3fDA%3D)

Budsjettenator er en enkel budsjett applikasjon utviklet med HTML, CSS og JavaScript.

Målet med prosjektet er å gi brukeren en ryddig oversikt over inntekter, utgifter og disponibelt beløp gjennom et moderne og brukervennlig grensesnitt.

## ✨ Funksjoner

- Registrere månedlig inntekt
- Legge til utgifter
- Beregne hvor mye penger som er igjen
- Oversiktlig dashboard
- Responsivt design
- Lokal lagring av data

## 🛠️ Teknologier

- HTML5
- CSS3
- JavaScript

## 🎯 Formål

Dette prosjektet er laget for å øve på frontend-utvikling og styrke ferdigheter innen:

- Strukturering av nettsider med HTML
- Styling med CSS
- Dynamisk funksjonalitet med JavaScript
- Arbeid med brukerinput og DOM-manipulasjon
- Lagring av data i nettleseren

## 🚧 Status

Prosjektet er under aktiv utvikling.

Planlagte funksjoner:

- Flere budsjettkategorier
- Grafisk oversikt over utgifter
- Månedlig historikk
- Eksport av budsjettdata
